To add yourself as a translator, simply go into `content/core/configs/userIds.js` and add your Roblox user id and your gh username!

``` js title='content/core/configs/userIds.js' linenums='1'
export const TRANSLATOR_USER_IDS = [
    '1564574922', // bogdan-glitchm
    '10646979010', // rav4toy
    '3121706', // AuroxNova
    '48255812', // aliceenight
    '315646839', // imderlord
    ...
    '0000000000', // ghost
    'Roblox UID', // your_gh_username
];
```
